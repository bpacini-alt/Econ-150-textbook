# Chapter 16 goods-dimensions practice: quality review

## Classification rule

- **Excludability:** Can people without permission or payment be kept from access through a workable rule and enforcement?
- **Rivalry:** Does one person's use reduce the quantity, space, capacity, or quality available to others?
- Public ownership or public funding does not by itself determine either dimension.

## Fast practice guardrails

The two Quick Sorts and four-category drag-and-drop use examples with the relevant access or capacity condition stated. Public libraries, public schools, and congestion-dependent examples stay out of this fast foundation set.

- **Private goods:** sandwich, sold-out airplane seat, grocery-store apple.
- **Club goods:** password-protected stream with ample capacity, uncongested toll bridge with controlled entry, subscription course with room for more viewers.
- **Common resources:** open-access fish, pasture with no enforced entry limits, forest with no permits or entry limits.
- **Public goods:** national defense, region-wide siren, publicly audible radio alert, unticketed fireworks visible across town.

Each drag-and-drop round includes all four categories. The two Quick Sort answer sequences vary their runs, so students cannot use a repeating left/right pattern.

## Slow edge-case set

The 15 sentence completions make the relevant boundary explicit:

| Cases | Intended distinction |
|---|---|
| Library entrance; school-district enrollment | Access rules and enforcement can make a publicly provided service excludable. |
| Library study seats; teacher tutoring time | A scarce seat or appointment is rivalrous when one person's use prevents another's. |
| Gated rose garden; crowded park bridge | A gate changes excludability; congestion changes rivalry. |
| Outdoor light show; enclosed tent show | A gate can exclude people from the viewing lawn while an outside view remains available. An opaque enclosure can make the performance itself excludable. |
| Encrypted radio; pool passes below capacity; pool at safe capacity | Encryption and passes change excludability; crowding at capacity changes rivalry. |
| Gated parking spot; campground reservation | Enforced access plus one-at-a-time use makes the specific space both excludable and rivalrous. |
| Paid parking beside an open beach path | Rights over the parking lot do not automatically restrict beach access. |
| One checked-out library book | A single physical copy is rivalrous even though the library is public. |
