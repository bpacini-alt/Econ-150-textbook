# Chapter 15 Tier 3 Import Pilot

This pilot imports the historical Elasticity practice quiz into the current Econ precise-practice engine.

## Source

- Structured source bank: https://github.com/bpacini-alt/practice-engines/blob/pilot/econ-ch15-elasticity-json/items/econ-150/ch15-elasticity-practice.json
- Original practice quiz and answer key are preserved in the practice-engines legacy archive.
- The imported bank contains 68 questions in four original pools. The textbook pilot exposes them through the engine's Tier 3/AP-style multiple-choice mode.

## Deliberate pilot status

Every item remains `legacy-unreviewed`. Treating the bank as Tier 3 here is an interface and learning-experience test, not a final difficulty classification. The pilot should help us see:

- whether the question presentation and answer randomization work;
- whether the feedback is useful enough;
- which legacy items actually deserve Tier 3 status;
- which items need diagrams, revision, or removal; and
- whether the five-question readiness bar feels sensible.

Questions 8, 9, 12, and 15 reference diagrams that were not available in the readable text extraction and need visual recovery before final use.

The pilot does not alter the chapter's FRQ or completion rules.
